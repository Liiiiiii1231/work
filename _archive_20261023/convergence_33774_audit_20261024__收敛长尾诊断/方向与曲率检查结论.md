# 梯度、方向与曲率检查结论

正式代码未修改。检查使用33774保存末态，5个状态共40个端点；方向比较使用30dBm场景8003，从同一末态一致重置RCG记忆后运行30轮，不能视为原1500轮轨迹的精确续跑。

1. 未发现统一的梯度符号反转。固定资源梯度与固定两轮FP候选目标的切向梯度夹角余弦最小0.995943。
2. 当前差分delta=1e-6有可观察数值误差。以1e-8估计为参照，投影梯度相对差异中位数0.6361%；delta=1e-7时中位数0.0070%。参照同样是有限差分，不是解析真值。
3. 仅把delta改成1e-7，30轮增益由0.006633768变为0.006651836，改善0.272%，没有证据显示能解决长尾。
4. PR+的beta最大553.542，实际方向与当前梯度夹角余弦最小0.017049。历史方向存在明显放大的样本，但不能仅凭beta大断言实现错误。
5. 每轮重启为梯度方向，30轮增益0.006783755，比当前RCG增加2.261%；候选FP调用2946降至2894。改善有限，不能认定重启会大幅减少完整收敛轮数。
6. 固定两轮FP候选目标的局部16维切空间Hessian，在此样本的特征值约-125002至-1766，曲率尺度比约70.8；跨端点耦合块占Hessian Frobenius范数约47.0%。1e-6和3e-6探针的整体Hessian相对差异0.120%。支持“局部曲率较大、方向之间尺度不同且相互耦合，逐端点更新只能接受小步”的解释；不是全局Hessian或唯一根因证明。

重要数值细节：直接对带早停的两轮FP调用求Hessian会出现假曲率，因为零位移点可能只跑1轮，邻点跑2轮。因此曲率诊断强制每点准确2轮，正式求解器不变。之前未作固定轮数时的中间Hessian估计不用于上述结论。

目前没有证据支持简单增大initial_outer_step来减少迭代。下一步如需修改算法，应在相同初态、预算和精度下比较方向尺度修正/曲率预处理或有条件重启，并以单位时间目标增益评估；不能只凭一次局部曲率直接替换正式算法。
